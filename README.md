# Webbus · Modern AI-implementering & Systemutveckling

Modern webbapplikation och plattform för **Webbus** i Kiruna, byggd med **Next.js 15 (App Router)**, **JavaScript**, **Tailwind CSS** och designsystemet **Nordic AI Enterprise** från Google Stitch.

Webbus hjälper företag att gå från AI-hype till mätbar produktivitet genom anpassade modeller (Claude, Gemini, GPT-4o) och robust, containeriserad systemutveckling.

---

## 🌟 Nyckelfunktioner

- **Nordic AI Enterprise Design:** Arktisk minimalism, responsiv layout och optimerad visuell hierarki.
- **5 Huvudsidor:**
  - **Start / Hem (/):** Hero med levande Kiruna-noder, Dual Pillars och spjutspetsteknologi.
  - **Tjänster (/tjanster):** Djupdykning i modeller, 3-stegs implementeringsmetod och **Interaktiv AI ROI-kalkylator**.
  - **Om & Team (/om-team):** Ingemar Strålberg, 25+ års erfarenhet, nätverksmodell och ingenjörsfilosofi.
  - **Kunder & Referenser (/kunder):** Verifierade nyckeltal (-50% IT-kostnader), kundcase och leveransbibliotek.
  - **Kontakt & Support (/kontakt):** Akut fjärrsupport, kontaktkanaler, validerat kontaktformulär och inbäddad Kirunakarta.
- **Globala funktioner:**
  - Bokningsmodal för 30 minuters förutsättningslösa möten.
  - TeamViewer QuickSupport-modul med snabbstart och 3-stegsguide.
  - 100% ren UTF-8-teckenkodning för svenska språket (Å, Ä, Ö, å, ä, ö).

## 🚀 Kom igång lokalt

1. Klona repositoryt:
   `ash
   git clone https://github.com/ingemarstralberg-art/webbus.git
   cd webbus
   `

2. Installera beroenden:
   `ash
   npm install
   `

3. Starta utvecklingsservern:
   `ash
   npm run dev
   `
   Öppna [http://localhost:3000](http://localhost:3000) i webbläsaren.

4. Bygg för produktion:
   `ash
   npm run build
   npm start
   `
